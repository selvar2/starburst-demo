Core Platform

The Four Sophia Products

Four interconnected capabilities forming a unified enterprise intelligence platform for State Farm leaders.

📊
Sophia Metric
Metric Governance

A central repository ensuring everyone uses the same definition and calculation for business metrics — eliminating confusion and inconsistency across all reports and dashboards.

🤖
Sophia Chatbot
Agentic AI · LLM

A management console allowing authorized users to configure the system. Integrates with the Context Store to intelligently decide which AI agent to invoke — Visualization, Budget, or Monitoring.

🧠
Sophia Context Store
Knowledge Base · RAG

An intelligent knowledge base maintaining descriptions and relationships of all data assets — helping users understand what data means, how it connects, and providing business context for leaders.

🔔
Sophia Business Monitoring
Real-time Alerts · Dynatrace

An automated system continuously watching key metrics, alerting leaders to important changes, emerging opportunities, or problems — proactively surfacing insights without manual effort.

Who Uses Sophia?

15 active users across two primary leadership roles — each with distinct access patterns and capabilities.

👔
ET Leaders
Executive / Senior Leadership · 5 users
  • Access real-time business metric dashboards and trends
  • Interact with Sophia Chatbot for ad-hoc analysis via natural language
  • Receive automated business monitoring alerts proactively
  • View budget vs. actuals and timesheet data via visualizations
🏢
FO Leaders
Field Operations Leadership · 10 users
  • Configure and customize Sophia metric definitions
  • Manage Budget Admin — upload and edit CSV budget data
  • Access trusted data sources: budget, timesheet, hierarchy
  • Manage Context Store and data asset relationships
